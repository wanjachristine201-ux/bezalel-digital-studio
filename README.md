# Bezalel Digital Studio - Official Website

Professional website design and development for businesses in Kenya and beyond.

## Tagline

"Your business deserves to be seen."

## Project Overview

This is the official website for Bezalel Digital Studio, a new digital studio based in Kenya. The website showcases the studio's services, process, and portfolio to help small and medium-sized businesses establish a professional online presence.

## Technology Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Git and GitHub for version control

## Features

- Responsive, mobile-first design
- Accessible navigation with semantic HTML
- Smooth scrolling and interactive elements
- Premium design with navy, ivory, and gold color scheme
- Clear information architecture

## Sections

1. **Navigation** - Sticky navigation with mobile toggle
2. **Hero** - Main headline and call-to-action
3. **About** - Introduction to the studio
4. **Services** - Business websites, redesigns, and landing pages
5. **Portfolio** - Demonstration projects (real client work coming soon)
6. **Founder** - Honest introduction to the founder
7. **Process** - Discover, Plan, Build, Test, Launch
8. **Contact** - Enquiry call-to-action with placeholders
9. **Footer** - Contact info, navigation, and copyright

## How to Run Locally

1. Clone or download this repository
2. Open `index.html` in a web browser
3. Or use a local server (recommended):
   - Using Python: `python -m http.server`
   - Using Node.js: `npx serve`
   - Using VS Code: Install "Live Server" extension and click "Go Live"

## Design System

### Colors
- Navy: `#0a2342` (primary)
- Navy Light: `#163560`
- Ivory: `#f8f5f0` (background)
- Ivory Dark: `#e8e4db`
- Gold: `#c9a227` (accent)
- Gold Light: `#d4b84a`

### Typography
- Font: System fonts (San Francisco, Segoe UI, Roboto)
- Responsive sizing for all screen sizes

### Spacing
- Consistent spacing scale using CSS variables
- Generous whitespace for readability

## Deployment

When ready for production, deploy to Vercel:
1. Push code to GitHub repository
2. Connect repository to Vercel
3. Deploy with default settings
