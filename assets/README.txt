Assets Folder
=============

This folder is reserved for images and other media assets.

When adding images:
- Use only legally usable images (e.g., Unsplash, Pexels, or your own photos)
- Clearly credit image sources in your documentation
- Never misrepresent demonstration projects as paid client work
- Use appropriate alt text for accessibility

Current placeholders in the website:
- Founder photo placeholder
- Portfolio project images (3 demonstration projects)
- Service icons (currently using SVG icons inline)

Note: The website currently uses CSS gradients and inline SVG icons as placeholders.
